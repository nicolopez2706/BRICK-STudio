COLECCIÓN

La colección.

Seis lecturas de una misma pieza. El sistema se comporta como un organismo sensible: respira, filtra, se abre, se protege. Cada transformación material equivale a un gesto humano.

CONCEPTO
LA MATERIA VIVA

La materia
viva.

Así como el cuerpo se abre para recibir y se cierra para cuidar, el sistema se adapta para equilibrar convivencia y soledad.

Cada módulo posee dos caras con morfologías distintas: la misma pieza, leída de dos maneras diferentes según cómo se la combine.

Habitar, entonces, no es solo ocupar un espacio, sino una experiencia en la que se coexiste con los otros desde la materia viva del entorno.

Módulo inicial

Incluye guías de instalación, columnas estructurales y piezas cerámicas modulares.

Piezas cerámicas

Elementos principales del sistema, diseñados para generar división, textura y composición visual.

Accesorios

Complementos intercambiables que amplían las posibilidades de uso, soporte y personalización.
